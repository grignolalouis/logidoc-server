# logidoc_list_documents

List all indexed documents.

## Parameters

None.

## Returns

Markdown list of documents with IDs, names, and status.

```
- **report.pdf** [5d04eeed-076d-...] (ready)
  Technical report on the Ora platform.
- **go-book.pdf** [d41ad337-7e2a-...] (ready)
```

## When to use

Call this first to see what documents are available before querying a specific one.
